# 随行提词

包含 iPhone 原生 App 和微信小程序：输入文案、调整提词速度，边看稿边拍摄，将视频保存到相册。提词文字不写入视频。

## 项目

- `iPhone提词器/`：SwiftUI + AVFoundation，最低 iOS 17。使用 Xcode 打开 `Teleprompter.xcodeproj`，选择自己的签名团队后运行。详见项目内 README。
- `微信提词器验证版/`：使用微信开发者工具导入该目录。支持横竖屏、多种画面比例、拖动与缩放提词窗口，以及录制和相册保存。

## 小程序反馈功能状态

文字反馈页面及云函数已实现，私有数据库、反馈函数及清理定时任务已部署到项目配置中的云环境。清理函数空集合云端测试通过；真实用户提交、内容安全接口权限及 iPhone 预览仍待联调验收。当前反馈开关用于内部联调，不代表已完成正式上线准备。

使用自己的小程序时，修改 `微信提词器验证版/project.config.json` 的 AppID，以及 `config/feedback.js` 的云环境 ID；未完成部署验收时将 `enabled` 设为 `false`。为 `feedback`、`feedback_limits` 设置仅管理员可访问权限，各建立 `expiresAt` 升序索引。部署两个云函数，并配置 `cleanupFeedback` 的 `feedbackRetention` 每日定时任务。正式发布前完成隐私指引、联系渠道和真机验证。

## 本地测试

```sh
cd 微信提词器验证版
node --test tests/*.test.js
```

当前 45 项测试通过。云函数依赖使用 npm lockfile 锁定；官方 SDK 的传递依赖仍有已知审计问题，需要在发布前继续评估和处理。
